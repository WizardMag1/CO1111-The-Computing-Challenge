Project Scope

What is CyberQuest?

Developed for Coursework Assessment 1 in CO1111 (The Computing Challenge) at the University of Central Lancashire (UCLan Cyprus).

The challenge requires teams to engineer an interactive, mobile-optimized Web Application capable of interacting with the Code Cyprus Treasure Hunt API.

Unlike standard quiz applications, players must physically visit specific geographic checkpoints to unlock questions, verify coordinates, and submit answers. The server calculates score adjustments in real-time, penalizing incorrect attempts and skips while rewarding speed and accuracy.

Technical Highlights

  • Adaptive Input Forms: Dedicated UI controls for Boolean, Multiple Choice, Numeric, and Text questions.
  • Defensive Networking: Robust fetch requests with timeout handling and error recovery.
  • Session Resumption: Seamless state hydration through browser localStorage.
  • Progressive Web App: Mobile installability with offline asset caching.
Gameplay Guide

How to Play CyberQuest

Three simple steps to compete in campus treasure hunts.

01

Join a Challenge

Launch the app, pick an active hunt from the Code Cyprus server, and enter your unique player nickname.

02

Navigate & Sync GPS

Follow the geographic clues to physical campus checkpoints. The app automatically verifies your real-time coordinates.

03

Solve, Scan & Score

Answer clues using tailored input controls or scan physical QR codes to score points and climb the live leaderboard.
