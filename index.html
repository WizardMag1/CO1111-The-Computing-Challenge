Project Scope

What is CyberQuest?

Developed for Coursework Assessment 1 in CO1111 (The Computing Challenge) at the University of Central Lancashire (UCLan Cyprus).

CyberQuest is an interactive, location-aware mobile web application built to play the Code Cyprus Treasure Hunt. Unlike a standard quiz, players cannot simply guess answers from home—they must physically walk to specific campus locations to unlock clues, verify their GPS coordinates, and submit their responses.

The application communicates asynchronously with the Code Cyprus REST API, managing live scoring, time penalties, question skips, and instant leaderboard rankings.

Key Technical Features

  • Adaptive UI: Automatically changes inputs for Boolean, Multiple Choice, Numeric, and Text questions.
  • Live Geolocation: Continuous, rate-limited GPS synchronization to prove player proximity.
  • Camera QR Scanner: Instant clue scanning using your device camera.
  • Session Recovery: Automatically saves your progress so you never lose your score if you reload.

1. Mobile-First Web Application

The application must function seamlessly on mobile devices while maintaining full desktop compatibility.

Responsive Design

Fluid layouts that adapt to different screen sizes using CSS media queries and flexible grids.

Touch Optimization

Large touch targets, swipe gestures, and mobile-friendly navigation patterns.

Performance Optimization

Lightweight zero-dependency architecture, optimized asset delivery, and efficient DOM updates.

Browser Compatibility

Testing across Chrome, Firefox, Safari, and Edge on both mobile and desktop platforms.

2. Code Cyprus API Integration

Real-time interaction with the Code Cyprus backend services.

Session Management

Real-time session handshake via /start endpoint and active session tracking.

Game State Management

Real-time updates for current question, score, time, and leaderboard position.

Question Handling

Dynamic question fetching based on game state and progression.

Live Leaderboard

Real-time display of top-ranking players and their scores.

3. Session Persistence

Ensuring user progress is saved even if the application is refreshed or closed.

Local Storage

Saving game state in browser's localStorage for instant recovery.

Session Recovery

Automatic restoration of game state on page reload.

State Persistence

Browser localStorage synchronization ensuring continuity across refreshes and signal drops.

Progress Visualization

Displaying saved progress and achievements to the user.

4. Interactive Gameplay Features

Engaging features that enhance the treasure hunt experience.

QR Code Scanner

Integrated camera functionality for scanning QR codes at physical locations.

GPS Verification

Location-based validation to ensure players are at the correct site.

Adaptive UI Inputs

Dynamic form generation based on question type (Boolean, MC, Numeric, Text).

Progress Tracking

Real-time monitoring of completed questions, score, and time remaining.

5. Testing and Validation

Rigorous testing procedures to ensure application quality and reliability.

Unit Testing

Automated tests for game logic, API integration, and session management.
